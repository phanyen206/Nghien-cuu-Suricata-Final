# Dữ liệu thực nghiệm

Thư mục lưu trữ dữ liệu đầu vào phục vụ quá trình trích xuất đặc trưng,
huấn luyện và đánh giá mô hình Decision Tree.

## Thành phần

- `features.csv`: dữ liệu đặc trưng được trích xuất từ lưu lượng mạng.
- `alerts_scan.tsv`: dữ liệu cảnh báo phục vụ đối chiếu.
- `pcap/`: các tệp PCAP đã được cắt từ bộ dữ liệu CIC-IDS2017.
